# Luva’s Healthy Store — V1

Personalización de la plantilla comercial Next.js para Luva’s Healthy. Incluye las 9 capturas aportadas, exportadas a WebP en `public/images`, identidad visual, portada, catálogo y sección de Chef Valeria.

## Ejecución local

Terminal Ubuntu Linux, usuario de desarrollo (sin sudo):

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abrir `http://localhost:3000`. El checkout y owner login necesitan variables de entorno y configuración segura.

**No activar pagos ni publicar en producción sin confirmar precios, políticas y seguridad.**

Revisar `docs/LUVA_CONTENT_REVIEW.md`.
